# Dependencias internas de [facturador/config.py](facturador/config.py)

## Visión general
[facturador/config.py](facturador/config.py) define rutas y constantes de configuración compartidas por la aplicación de facturación.

## Módulos propios utilizados

- Ningún módulo interno adicional. Todas las referencias pertenecen a la biblioteca estándar (`os`).

## Conclusión
[facturador/config.py](facturador/config.py) actúa como fuente única de rutas y endpoints sin acoplarse a otros componentes. Esto simplifica futuros ajustes de configuración dentro del plan de refactor documentado en [facturador/docs/refactor/01_plan_refactorizacion_ui.md](facturador/docs/refactor/01_plan_refactorizacion_ui.md).
